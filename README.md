# Browser Fingerprinting Privacy Study

An independent measurement study evaluating client-side browser fingerprinting vectors, signal stability, and privacy defense behaviors.

## Project Structure

- `index.html` — Collector interface
- `app.js` — Client-side attribute extraction
- `style.css` — Interface styling
- `project-plan.md` — Experimental scope & methodology
- `ethics.md` — Data handling & privacy boundaries
