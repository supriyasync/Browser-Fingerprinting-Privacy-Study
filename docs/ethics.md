# Ethical Scope & Guidelines

This project is conducted strictly for educational and scientific privacy evaluation.

### Boundaries:

1. **Localhost Execution:** All data collection runs locally on tested clients.
2. **Zero Surveillance:** No network identifiers (IP addresses), geographic locations, or private browsing histories are collected.
3. **Consent & Privacy:** No third-party profiling or tracking across the web. Any external test device used is subject to prior explicit consent.
