# Git Commands Reference Cheatsheet

### 1. Check Working Tree Status

git status

Shows modified, untracked, and staged files.

---

### 2. Stage Changes

git add
git add .

Stages a specific file or all modified/new files.

---

### 3. Record Snapshot (Commit)

git commit -m "Descriptive present-tense commit message"

---

### 4. Push to Remote Repository

git push
git push origin

Pushes commits on current branch or pushes an annotated tag.

---

### 5. Inspect History

git log --oneline

Displays compact single-line commit history.
